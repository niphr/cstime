# Norwegian workdays and holidays by isoyearweek

Norwegian workdays and holidays by isoyearweek

## Usage

``` r
nor_workdays_by_isoyearweek
```

## Format

- isoyearweek:

  YYYY-WW

- public_holiday:

  The proportion of the days within the isoyearweek that are public
  holidays

- freeday:

  The proportion of the days within the isoyearweek that are either
  public holidays or Saturday/Sunday

- workday:

  1 minus freeday

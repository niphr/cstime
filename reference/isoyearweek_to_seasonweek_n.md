# ISO yearweek to season week (numeric). Season week 1 is ISO week 35.

ISO yearweek to season week (numeric). Season week 1 is ISO week 35.

## Usage

``` r
isoyearweek_to_seasonweek_n(x)
```

## Arguments

- x:

  ISO yearweek

## Value

Season week in numeric

## Examples

``` r
isoyearweek_to_seasonweek_n(c("2021-01"))
#> [1] 19
```

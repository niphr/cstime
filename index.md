## Overview

[cstime](https://niphr.github.io/cstime/) provides date and time
functions for public health purposes.

`cstime` provides convenient and consistent conversion between

- isoyear
- isoweek
- calyear
- season week

In addition, cstime provides calendar data for reference.

Read the introduction vignette
[here](https://niphr.github.io/cstime/articles/cstime.html) or run
[`help(package="cstime")`](https://niphr.github.io/cstime/reference).

## Overview

[cstime](https://niphr.github.io/cstime/) provides date and time functions for public health purposes. It covers conversion between date, ISO week, ISO yearweek, ISO year, calendar month and year, and season week, together with bundled calendar reference data.

Read the introduction vignette [here](https://niphr.github.io/cstime/articles/cstime.html) or run `help(package="cstime")`.
